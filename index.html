Data Notes & Implementation Notes

What is already encoded

  • Detailed individual rosters for MD batches 18, 19, 20, 21, and 22.
  • Batch-level counts for admitted and, where recorded, completed / graduated counts.
  • A CSV export of the current registry.
  • UP-inspired UI using the provided SHS and UP logos.

What still needs verification

  • Historical detailed rosters for earlier notebook batches.
  • Formal validation of spelling, completion status, and later licensure outcomes.
  • Optional migration to a database once you are ready for live editing.
