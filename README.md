# UPM SHS Department of Medicine Alumni Tracking System

GitHub Pages-ready static site. Upload the contents of this folder to the repository root.

## Included data
- 22 MD batches
- 327 roster entries transcribed from the uploaded handwritten ledger
- Batch admission/completion/licensure totals where recorded
- Source page + row for auditability
- Historical entries default to **Needs verification**

## Files
- `index.html` – complete self-contained site (CSS, JS, and logos embedded)
- `data/alumni_registry.csv` – flat roster export
- `data/batch_summary.csv` – batch totals
- `data/alumni_data.json` – structured source data
- `assets/` – original logo image files

Because handwriting is difficult to read on several pages, review spellings and annotations against official records before institutional use.
